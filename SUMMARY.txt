PROJECT OVERVIEW
================================================================================

Full-stack application for managing consultation recordings with AI-powered 
transcription and summarization using Google Gemini 1.5 Flash.

MAIN FEATURES:
  • User Authentication (JWT-based)
  • Record Management (Upload, organize, delete)
  • AI Transcription (Google Gemini)
  • AI Summarization (Google Gemini)
  • Client Management
  • File Storage (Cloudinary + Local)
  • Responsive UI (React + Tailwind CSS)
  • Production-Ready Docker Setup

AI FEATURES & USAGE
================================================================================

AI MODEL USED: Google Gemini 1.5 Flash

WHY THIS MODEL?
  ✓ Multimodal (audio, video, text)
  ✓ Large context window
  ✓ Fast processing
  ✓ Cost-effective
  ✓ Reliable

WHAT IT DOES:
  1. Transcribes audio/video to text
  2. Generates professional summaries
  3. Extracts action items
  4. Identifies key points

HOW IT WORKS:
  User uploads file
    ↓
  Backend receives via Multer
    ↓
  File uploaded to Gemini API
    ↓
  Gemini processes asynchronously
    ↓
  Results saved to MongoDB
    ↓
  Temporary file deleted
    ↓
  User views in frontend

COST PER RECORDING:
  • 5 min audio: ~$0.001
  • 30 min audio: ~$0.005
  • 60 min audio: ~$0.01

FREE TIER LIMIT:
  • 15 requests/minute
  • 60 requests/day
  • Sufficient for 1-2 recordings/day per user

API KEY SETUP:
  1. Go to https://ai.google.dev
  2. Click "Get API Key"
  3. Copy key to .env as GEMINI_API_KEY

API ENDPOINTS
================================================================================

AUTHENTICATION:
  POST   /api/auth/register      Create account
  POST   /api/auth/login         Login & get JWT token

CLIENTS:
  GET    /api/clients            List clients
  POST   /api/clients            Create client
  GET    /api/clients/:id        Get client details
  PUT    /api/clients/:id        Update client
  DELETE /api/clients/:id        Delete client

RECORDINGS:
  GET    /api/recordings                  List recordings
  POST   /api/recordings                  Upload recording
  GET    /api/recordings/:id              Get recording
  DELETE /api/recordings/:id              Delete recording
  POST   /api/recordings/:id/transcribe   AI transcription
  POST   /api/recordings/:id/summarize    AI summarization

FILE UPLOADS:
  POST   /api/upload             Upload file
  GET    /uploads/:filename      Download file

Note: Most endpoints require JWT token in Authorization header

================================================================================
DATABASE SCHEMA
================================================================================

USER:
  _id: ObjectId
  email: String (unique)
  password: String (hashed with bcryptjs)
  name: String
  createdAt: Date
  updatedAt: Date

CLIENT:
  _id: ObjectId
  userId: ObjectId (foreign key to User)
  name: String
  email: String
  phone: String
  address: String
  notes: String
  createdAt: Date
  updatedAt: Date

RECORDING:
  _id: ObjectId
  userId: ObjectId (foreign key to User)
  clientId: ObjectId (foreign key to Client)
  fileName: String
  fileUrl: String
  transcription: String
  summary: String
  uploadedAt: Date
  createdAt: Date
  updatedAt: Date

================================================================================
TROUBLESHOOTING
================================================================================

MONGODB CONNECTION ERROR:
  • Check MONGODB_URI is correct
  • Ensure IP whitelist includes 0.0.0.0/0 in MongoDB Atlas
  • Verify MongoDB user password

TRANSCRIPTION NOT WORKING:
  • Check GEMINI_API_KEY is set
  • Ensure file is audio/video format
  • Check backend logs for errors

CORS ERRORS:
  • Verify VITE_API_URL matches backend URL
  • Check FRONTEND_URL in backend env vars
  • Restart services

COLD START TAKING TOO LONG:
  • Render free tier spins down after 15 min inactivity
  • Use UptimeRobot (free) to keep warm
  • Consider upgrading to paid tier
